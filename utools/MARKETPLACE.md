# uTools 上架信息

## 插件名称
Unity CLI GUI

## 插件描述

Unity CLI GUI 是一款为 Unity 开发者打造的全能管理工具，将 Unity CLI 的全部能力以可视化界面呈现。覆盖编辑器安装与管理、项目管理、构建测试、MCP/AI 集成等 36 个 CLI 顶级命令，提供 104 个功能接口，支持 macOS、Windows、Linux 三平台。

核心功能：
• 编辑器管理 — 安装/卸载/升级 Unity 编辑器，模块增删，版本切换，设默认版本
• 项目管理 — 项目列表（可展开卡片），内联版本/平台切换，Git 信息，磁盘占用，搜索排序，右键菜单（13+ 项含链接/取消链接/克隆/导出/导入）
• 构建与测试 — 可视化配置 + 实时日志流（支持暂停/过滤/清空），结果持久化
• MCP/AI — Pipeline 包管理（安装/升级/状态），编辑器命令执行，MCP 客户端配置（Claude/Cursor/Windsurf 等）
• AI Chat — 自然语言转 CLI 命令，4 标签设置（通用/模型/MCP/技能），自定义模型与 Base URL，OpenAI 兼容网关
• 下载管理 — 编辑器安装/构建/测试/升级任务统一管理，实时进度
• 内置终端 — 命令历史（上下箭头），JSON/Human 双模式
• 日志查看 — Hub 日志流，follow 模式，级别过滤
• 系统设置 — 语言设置（10 语言全覆盖），代理配置，分析同意，Auth 登录/登出，许可证管理，CLI 自升级，Hub 安装检测
• CLI 安装/卸载 — 一键安装 Unity CLI（官方脚本），卸载带日志，安装后自动检测

界面特性：
• 10 种语言全覆盖（中文/英文/日文/韩文/德文/西班牙文/法文/葡萄牙文/俄文/意大利文），零硬编码字符串
• 深色/浅色/跟随系统主题
• 全局 Toast 通知
• 项目元数据本地存储（自定义名称、图标、备注）

## 版本描述 (v0.0.1)

首个 uTools 插件版本。

功能清单：
- 12 个功能页面（Dashboard、编辑器、项目、构建、测试、MCP/AI、AI Chat、下载、终端、日志、设置、关于）
- 104 个后端接口，覆盖全部 36 个 Unity CLI 顶级命令
- 编辑器管理：安装/卸载/升级/设默认/模块增删/刷新
- 项目管理：列表/创建/添加/升级/删除/克隆/链接/取消链接/导出/导入/模板管理
- 构建测试：流式日志、暂停/过滤/清空、结果持久化
- MCP/AI：Pipeline 管理、编辑器命令执行、MCP 客户端配置
- AI Chat：自然语言转命令、自定义模型、MCP 服务、自定义技能
- CLI 一键安装/卸载（带日志流 + 自动检测）
- Auth 登录（后台启动 + 轮询检测，支持 OAuth 回调）
- 10 语言国际化、深色/浅色/系统主题
- 许可证管理、Hub 检测
- 跨平台支持：macOS (arm64/x64)、Windows、Linux

## 开发者备注
本插件需要系统已安装 Unity CLI 工具（可在设置页一键安装）。插件通过 Node.js preload 脚本调用 unity CLI 二进制，不依赖任何后端服务。AI Chat 功能需要用户自行配置 API 密钥和网关地址，所有数据存储在本地。
